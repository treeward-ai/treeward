# Security Policy

## Reporting a Vulnerability

Treeward is a security-sensitive control plane for kernel micro-patching and attestation. Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately by emailing **security@treeward.ai** or using GitHub's private vulnerability reporting ("Report a vulnerability" in the Security tab).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- Affected versions or commit SHAs.

We will acknowledge receipt within 72 hours and work with you on a coordinated disclosure timeline.

## Supported Versions

Treeward is currently in early preview (`main`). Security fixes are applied to `main` and the latest tagged release.
